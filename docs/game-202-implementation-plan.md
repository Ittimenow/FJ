# Реализация типа игры 202

План одобрен пользователем сообщением «Приступай». Публикация и миграция production в это одобрение не входят.

## Область

- Отдельный `GameType`: 101/202 независимо от SOLO/MULTIPLAYER и технического rulesVersion.
- Полный набор 138 карточек, 12 стартовых портфелей, правила и реестр расхождений.
- Сохраняемое состояние с точными денежными расчётами, собственными сроками опционов, очередью решений всех игроков, обязательствами, предложениями и долями.
- Создание партии, оба круга, портфель, торги, переговоры, банк, банкротство, история, победа, боты.
- Изоляция от старых действий 101, проверка ревизий и транзакционная блокировка.

## Файлы

- `packages/shared/src/game-202/`: реестр карточек, портфели, чистый движок, политика ботов.
- `packages/database/prisma/schema.prisma`, `prisma/deploy/20261111_add_game_202.sql`: аддитивная схема, существующие игры остаются 101.
- `apps/api/src/games/`: создание и запуск, команды, снимки, боты, DTO, контроллер.
- `apps/web/src/components/game/`: выбор правил и панель 202 в существующей игровой комнате.
- `scripts/prepare-202-cards.mjs`, `dist/recognized_202_cards_ru.json`, `reports/card-set-202.md`: детерминированная сборка и импорт.
- `docs/game-202-rules.md`, `docs/bot-rules.md`, `docs/changes.json`, пользовательское руководство и публичная копия правил.

## Проверка

Примеры расчётов из пособия; выполнение всех 138 карточек; сроки опционов, дробления, банкротства, ипотека при частичной продаже, D2Y и права участников; сквозная симуляция до победы; сохранение/восстановление; параллельные команды; регрессия 101; повторный импорт в изолированной PostgreSQL; desktop/mobile; `npm test`, `npm run typecheck`, `npm run build`, `npm run changes:check`.

## Локальная подготовка и публикация

1. Собрать shared и проверить карточки: `npm run build --workspace=@cashflow/shared`, `node scripts/prepare-202-cards.mjs --check`.
2. На явно выбранной БД выполнить аддитивный SQL `packages/database/prisma/deploy/20261111_add_game_202.sql`, затем `npm run db:generate`.
3. Выполнить dry-run импорта набора «202», применить импорт, повторить dry-run (все 138 unchanged).
4. Выпустить API и web одной версией, содержащей этот движок, затем проверить создание и запуск обеих разновидностей партии.
5. Для production сначала получить отдельное разрешение на конкретный релиз и целевую БД. Обычный полный seed для обновления колоды не требуется.
