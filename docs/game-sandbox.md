# Персональная песочница игры

Песочница предназначена для ручной проверки ситуаций в 101 и 202 на обоих кругах. Создание доступно из разделов «Обзор» и «Игры» административной панели. Во время партии кнопка с колбой «Песочница» находится в общем игровом меню.

Доступ разрешён только активному аккаунту с ролью ADMIN и email из серверной переменной `SANDBOX_ADMIN_EMAIL`. Пустое значение отключает доступ. После изменения переменной требуется перезапуск API. Наличие роли администратора у другого аккаунта не даёт доступ к созданию, просмотру и управлению песочницей.

В партии два участника: администратор и «Второй игрок». Выберите участника в панели и закройте её, чтобы выполнять действия через обычные формы. Второй аккаунт не нужен. Автоматические ходы отключены; выбранные фишки сохраняются при повторе сценария.

## Настройка и повтор

1. Выберите круг и первого участника хода.
2. Настройте наличные и позицию каждого участника. Для большого круга задайте начальный доход и приобретённые активы.
3. На малом круге найдите карточку по названию, тексту или номеру. Предпросмотр использует общую игровую карточку. Добавьте допустимый актив с количеством или назначьте следующее выпадение.
4. Задайте следующий бросок: одна кость на малом круге, две на большом. После его использования следующие броски снова случайны.
5. Нажмите «Применить и начать заново». Все изменения применяются вместе; предыдущий запуск завершается. Стартовые активы выдаются без списания заданных наличных, их доходы и обязательства рассчитываются обычными правилами.
6. Проверяйте действия обоих участников. «Вернуть исходную ситуацию» повторно применяет последний сохранённый сценарий, включая карточки и кубики. Настройки сохраняются после перезагрузки страницы.

Назначенная карточка выпадает при следующем обращении к её колоде во время хода выбранного участника. Это не отменяет игровых правил: например, на клетке «Возможность» нужно выбрать соответствующую колоду. На большом круге события определяются позицией и броском. Активы с риском в исходной ситуации считаются уже успешно приобретёнными.

Песочница не публикуется в открытом списке, не создаёт результаты для статистики и публикаций. Обычные партии используют прежние правила случайного выпадения и поведения ботов. История текущего запуска начинается заново; сохранённые серверные события не удаляются.

## Проверка разработки

Серверные проверки: `npm run test --workspace=@cashflow/api` и `npm run typecheck`.

Интеграционный набор `apps/api/src/games/sandbox.integration.test.ts` принимает только `FJ_TEST_DATABASE_URL` с адресом `127.0.0.1:55439`. База должна быть временной, со схемой проекта. Набор сам создаёт пользователей, наборы карточек и профессии. По умолчанию его данные удаляются после проверки.

Для браузерных проверок сохраните данные набора с `FJ_SANDBOX_KEEP_FIXTURES=1` и `FJ_SANDBOX_ARTIFACT_DIR` во временной папке, соберите API и запустите `tests/fixtures/sandbox-api.mjs` с теми же переменными. Это локальный проверочный сервер с настоящей игровой логикой и временной базой; он слушает только `127.0.0.1:55440` и не предназначен для публикации. Затем выполните `FJ_SANDBOX_API=http://127.0.0.1:55440 npx playwright test tests/sandbox.spec.ts --project=chromium --workers=1`.
