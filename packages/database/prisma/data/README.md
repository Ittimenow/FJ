# Справочник городов России

`russian-cities.csv` содержит 1117 городов с регионами и идентификаторами ФИАС.
Исходный набор: [epogrebnyak/ru-cities](https://github.com/epogrebnyak/ru-cities),
составленный на основе публикаций Росстата и идентификаторов ФИАС.

`russian-city-aliases.json` хранит предпочтительные написания названий с буквой
`ё`. Поиск в приложении считает `е` и `ё` эквивалентными.
