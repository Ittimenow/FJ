# Правила создания изображений для «Финансового путешествия»

## Главный принцип

Тема может быть любой. Единство серии создаёт визуальный стиль: все объекты выглядят так, будто их вручную слепили из пластилина и собрали в объёмную сцену. [Главное изображение сайта](https://gamefj.ru/financial-journey-board.webp) служит референсом фактуры и исполнения, а не сюжета.

## Визуальный стиль

Пластилиновые объекты с мягкими краями, слегка неровными формами и едва заметными следами ручной лепки. Поверхность тактильная, без пластикового блеска. Детали простые и хорошо читаются в небольшом размере. Свет тёплый и мягкий, тени плавные. Настроение дружелюбное, без излишней детскости.

Предпочтителен вид сверху под углом. Другой ракурс допустим, если он лучше раскрывает тему и сохраняет общий стиль серии.

## Палитра

Основные цвета сайта: фон `#FAF2E8`, тёмно-синий `#17243F`, синий `#2967DF`, оранжевый `#F98F2F`. Дополнительные цвета можно использовать по смыслу сюжета, сохраняя основные цвета узнаваемыми.

## Композиция

Один ясный главный сюжет и свободное место под заголовок. Главные объекты должны оставаться узнаваемыми после кадрирования для сайта и соцсетей. Текст, дату и логотип добавлять в макете, а не создавать внутри изображения. Для текста использовать шрифт сайта Manrope.

## Чего избегать

Глянцевого пластика, металла, стекла, фотореализма, плоских иконок и идеально ровных фабричных форм. Игровое поле, фишки и финансовые символы добавлять только тогда, когда они подходят выбранной теме.

## Готовый шаблон задания

**Тема изображения:** [впишите тему]

«Создать пластилиновую объёмную иллюстрацию на указанную тему. Показать: [сюжет или главные объекты]. Все элементы выглядят вручную слепленными из пластилина: мягкие края, небольшая естественная неровность форм, тактильная поверхность без пластикового блеска. Простая выразительная композиция, мягкий тёплый свет, плавные тени, светлый фон. Использовать палитру проекта с синими и оранжевыми акцентами. Оставить свободное место [укажите где] под текст. Без надписей и логотипа внутри изображения».
