# Проверка персональной песочницы

Дата: 14 ноября 2026. Изменения проверены локально; публикация на рабочий сервер не выполнялась.

## Что реализовано

Создание песочницы 101 или 202 из административной панели, ручное управление двумя участниками, начальные наличные и позиции, активы обоих кругов, назначенные карточки и следующий бросок, повтор сохранённой ситуации. Песочница использует действующие игровые правила, поля, формы, финансовые отчёты, карточки и историю действий. Предыдущие запуски исключаются из видимой и загружаемой истории; серверные события сохраняются.

Сервер проверяет активный статус, роль ADMIN, точное совпадение email с `SANDBOX_ADMIN_EMAIL` и владение партией. Пустая переменная отключает доступ. Локальное значение настроено на предоставленный владельцем аккаунт; в примерах окружения значение оставлено пустым. Схема базы не менялась. Для другого окружения нужно задать переменную и перезапустить API.

| `npm run typecheck` | Все рабочие пакеты проходят |
| `npm test` | Проверки прокси, API, веб-интерфейса и данных проходят; два интеграционных теста API без переменных окружения пропускаются |

| `npm run changes:check` | Журнал изменений корректен |

Интеграционный набор проверяет запрет для другого администратора и заблокированного владельца, выбор карточки, покупку обычным игровым действием, активы второго участника, управление его ходом, повтор сценария, отказ для команды предыдущего запуска, фильтрацию истории, сохранение настроек и отсутствие записей результатов. Для большого круга проверяется назначение собственности в 101 и 202. Тесты движка проверяют денежные единицы 202, сохранение чужих активов и скрытие внутренних управляющих данных.

## Ограничения проверки

Браузерный стенд использует настоящие React-компоненты, игровой сервис и отдельную PostgreSQL на 127.0.0.1:55439. HTTP-мост слушает только локальный адрес, авторизация задаётся тестовым владельцем, WebSocket заменён адаптером. Полный путь входа через JWT, сетевое восстановление WebSocket, рабочая база, Safari/Firefox и физические телефоны не проверялись. Не проигрывались все комбинации карточек, аукционов, банкротства и победы. Наличие двух пропущенных интеграционных тестов в общем наборе не считается их прохождением; песочница отдельно проверена с базой.

Описание использования: [docs/game-sandbox.md](../docs/game-sandbox.md).
