# Проверка досрочного выбытия игроков

Дата: 19 ноября 2026. Проверена локальная рабочая копия.

## Поведение

- Общая кнопка «Самовыпилиться из жизни» в отчёте игрока 101 и 202, включая большой круг; отдельное подтверждение с заданными подписями.
- Ведущий партии и администратор могут удалить активного человека или бота. Сервер проверяет права; обычный игрок может завершить только собственное участие.
- Выбывший остаётся в истории и результатах со своей фишкой и причиной выбытия. Его очередь решений закрывается, остальные участники продолжают игру. Последний выход завершает партию без победителя.
- Показатели выбывшего больше не меняются. Его владения на большом круге освобождаются, влияние на цены прекращается; в 202 его доли исключаются из активных сделок, доли остальных сохраняются. Исторические состояния остаются в журнале событий.
- Добровольный выход и удаление различаются в публикациях и результатах. Удалённые до старта участники без финансового отчёта не отмечаются как досрочно выбывшие из партии.
- Боты продолжают играть после явного выхода человека; отсутствие подключения вышедшего человека не ставит одиночную партию на паузу.

## Автоматические проверки

- `npm run typecheck` — все рабочие пакеты прошли проверку типов.
- `npm run test --workspace=@cashflow/api` — 440 пройдено, 2 пропущено. После последних уточнений отдельно повторены затронутые тесты выхода, подарков, результатов и публикаций.
- `npm run test --workspace=@cashflow/web` — 141 пройдено.
- Новые серверные тесты проверяют очередь ходов, выход вне своего хода, права ведущего и администратора, запрет удаления обычным игроком, удаление бота, рыночные решения, вложенные права и совместные предложения 202, завершение закрытого аукциона, последний выход, паузу и освобождение владений большого круга.
- Проверены публикации с добровольным выходом и удалением, отсутствие ложного победителя; запрещено менять баланс выбывшего подарком.
- `npm run changes:check` и `git diff --check` — пройдено.
- Механический анализ интерфейса сообщил только о существующем размере шрифта 10 px в неизменённой строке `financial-report.tsx`.

## Ограничения

Не запускалась реальная многопользовательская партия с PostgreSQL, несколькими подключениями и длительной игрой ботов. Серверные сценарии проверены тестами с имитацией хранилища; движок 202 используется настоящий. Публикации проверены как текст, отправка во внешние сервисы не выполнялась. Страница результатов проверена типами и логикой данных, отдельный браузерный прогон её нового блока не выполнялся. Firefox, WebKit, ширины 360/390/420/768/1023/1024 и длинные имена отдельно не проверялись; компоновка игровых полей не менялась.
