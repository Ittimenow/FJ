# Исправление проверки истории ходов в CI

Дата: 14 ноября 2026.

## Причина сбоя

В [Playwright Tests №69](https://github.com/Ittimenow/FJ/actions/runs/43571595813) для коммита `64b485d` не прошли 12 вариантов одного сценария: малый и большой круг, ширины 390 и 1440 пикселей, Chromium / Firefox / WebKit. Остальные 267 проверок прошли, 30 проверок песочницы были пропущены.

Тест ожидал точки через `::before` у событий истории. Действующий интерфейс и [регламент малого круга](../docs/rat-race-interface.md) предусматривают иконки действий. Проверка старого представления оставалась в `tests/fast-track.spec.ts` после изменения интерфейса.

Отдельный [CI №137](https://github.com/Ittimenow/FJ/actions/runs/43571595870) того же коммита завершился успешно: `build`, `image` и `deploy`, включая шаг Deploy to VPS. Ошибка относилась к независимому набору Playwright.

## Изменение

Обновлён только сценарий проверки в `tests/fast-track.spec.ts`:

- Проверяется последовательность иконок: текущее решение, бросок, банковская операция, продажа.
- У каждого маркера должна быть одна видимая SVG-иконка.
- Проверяются выравнивание по одной вертикали с допуском 1 пиксель, ненулевые размеры и нахождение всех маркеров внутри карточки хода.
- Сохранены проверки порядка действий, выбранной фишки второго игрока, финансовых сведений, общего контейнера хода и отсутствия горизонтального переполнения.
- Проверяется отсутствие старых точек `::before`. Скриншот сценария сохраняется в каталоге результата и прикладывается к отчёту Playwright.

## Результаты локальной проверки

Среда: macOS, Node.js 22.22.2, npm 10.9.7.

| Проверка | Результат |
| --- | --- |
| Исправленный сценарий: Chromium, малый / большой круг, 390×900 и 1440×900 | 4 из 4 прошли |
| Исправленный сценарий: WebKit, малый / большой круг, 390×900 и 1440×900 | 4 из 4 прошли в полном прогоне |
| Полный набор сценариев в Chromium и WebKit | 186 прошли, 20 пропущены, ошибок нет; 4,6 минуты |
| Firefox | Проверки не выполнены: браузер не запустился |
| `npm run changes:check` | Журнал корректен, 10 релизов |
| `git diff --check` | Ошибок пробелов нет |

Команда полного прогона двух доступных браузеров:

```sh
npx playwright test --project=chromium --project=webkit --workers=1 --reporter=line --output=test-results/timeline-regression
```

20 пропусков относятся к песочнице: по 10 сценариев на браузер. Они требуют отдельного локального API и `FJ_SANDBOX_API`; в этом прогоне сервер песочницы не запускался. Пропуски не считаются успешными проверками.

Первоначальный адресный запуск всех трёх браузеров выполнил четыре проверки Chromium, затем завершил первый запуск Firefox по тайм-ауту 180 секунд. Лог Firefox содержит `sandbox_extension_issue_file_to_process failed` и `Operation not permitted` для дочернего процесса. Повторная короткая проверка обычного запуска с окном также не смогла запустить браузер. Проверки безопасности не изменялись. Остаток адресного прогона был остановлен, после чего весь набор Chromium и WebKit выполнен отдельно.

Firefox необходимо проверить в Linux CI после отправки исправления. Успешное повторное выполнение GitHub Actions в рамках этой локальной проверки не заявляется.
